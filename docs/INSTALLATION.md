# Installation and troubleshooting

Follow the installation steps in [README](../README.md). If no dashboard appears, enable the addon at character selection, confirm the folder layout, and run `/wgf show`. For database features enable ForeverDB and restart; `/goatlas debug` reports database and native tooltip hook status. To capture errors use `/console scriptErrors 1` then `/reload`; redact private information before sharing. Back up SavedVariables while WoW is closed before upgrades. Do not delete history to troubleshoot unless you intentionally want a fresh profile.
