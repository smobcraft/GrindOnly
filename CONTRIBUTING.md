# Contributing

Report bugs and ideas through GitHub Issues when available. Include reproducible steps and versions; redact account names, chat, credentials and personal data. Do not upload SavedVariables. Maintainer approval is required for AI implementation and all merges/releases. Use a branch, keep changes scoped, add tests, and describe in-game verification. See AGENTS.md. License approval is pending; do not submit third-party code or assets without permission.
